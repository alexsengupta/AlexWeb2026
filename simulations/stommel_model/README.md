# Stommel Basin Simulator (Standalone)

This folder contains a standalone, no-build version of the Stommel Basin Simulator.

## Run locally

1. Open `index.html` directly in a browser (double-click or `file://`).
2. The simulation should start immediately. Use the control panel to adjust parameters.

If you prefer to serve it via a local server (recommended for consistent file access), you can run a simple static server from this directory.

## Notes

- This standalone version replaces the previous React/Vite app and does not require Node.js.
- The original Vite-based project is preserved in `stommel-basin-simulator-2.zip` if you ever need the source or build tooling again.
