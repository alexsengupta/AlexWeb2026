1. What the course map is

The course map is a web page that shows students how a major is built: which courses are core, which electives they choose from, how many they need, and which courses lead to which. Students can click a course to see its description, prerequisites and handbook link, and can pick a "pathway" to see which electives suit an interest such as meteorology or policy.

The BSc Climate Systems Science map. Each stage has three rows: core, prescribed electives, and degree requirements outside the major.

Everything the page shows comes from a handful of Excel files sitting next to it. To change the map, you change a spreadsheet. The page reads the spreadsheets fresh every time it loads, so there is no "publish" step beyond saving the file (and copying the folder to the website, see section 10).

Think of it as two separate kinds of information:

  • What the major says about its structure (which courses, which stage, core or elective, pathways). This lives in the program workbooks and is typed by a person.
  • What the university says about each course (title, terms, prerequisites). This lives in handbook.xlsx and is fetched automatically. You never type it, except for corrections in Overrides.

3. Golden rules for editing

  1. In every sheet, row 1 is a note, row 2 is the header, data starts on row 3. Don't rename sheets or change the header words; the page looks for them by name.
  2. Course codes must be exactly four capital letters and four digits, e.g. CLIM2001. A space or a lower-case letter means the page won't recognise it.
  3. Save as a normal Excel file (.xlsx). Don't change the file names unless you also change them in programs.xlsx.
  4. After any change, reload the page and press the Check button (section 9). It tells you if you've typed a code the handbook doesn't know, or listed a course in a pathway that isn't on the map.
  5. If you add a course code that is new to the map, run the scraper (section 7) so its title and details appear.

To add a course: add a row. To remove one: delete its row. To move it between stages: change the Stage number. Courses appear in the order of the rows.

5. Adding or changing a pathway (stream)

Pathways are the coloured buttons at the top ("Meteorology & Forecasting", "Government Policy"...). They are advice, not rules: clicking one highlights the electives that suit that interest and fades the rest. They live in the Streams sheet of the program workbook, one row per pathway.

Streams sheet
StreamColourDescriptionCourse 1Course 2Course 3Course 4Course 5...
Meteorology & Forecasting#c0392bAtmospheric dynamics and weather prediction; maths-heavyMATH1231MATH2011MATH2241MATH3201MATH3261
Government Policy#7d3c98Climate risk, energy transition and environmental managementGEOS1701BEES2041GEOS2241GEOS3761GEOS3922
  • To add a pathway: add a row. Give it a name, a colour, a one-line description, and list its courses across the row. Order doesn't matter, and a course can be in several pathways.
  • To change one: edit the codes in its row. To remove one: delete the row.
  • Colour is a six-character "hex" code with a # in front, e.g. #2471a3. Any web colour picker will give you one. Pick colours that are easy to tell apart.
  • Only list electives. Core courses are already compulsory, so listing them in a pathway means nothing; the Check button will warn you.
  • Every course in a pathway must already be in the Structure sheet's elective pool for that program.
  • A program with no pathways (the minor) just has an empty Streams sheet with the header row.
With "Meteorology & Forecasting" pressed, its electives are highlighted in the pathway's colour and the others fade.

6. Adding a new program or a new major

Two situations. A new program of an existing major (say, the Climate minor was added alongside the BSc and AdvSci) becomes another button next to BSc / AdvSci / Minor. A new major altogether (say, Geology, or Marine Science) gets its own entry in a drop-down list at the top of the page; the drop-down only appears once there is more than one major.

Either way the steps are the same:

  1. Copy an existing program workbook and rename the copy, e.g. GEOSA1_bsc.xlsx. Copy the one closest to what you need: a BSc major from CLIME1_bsc.xlsx, a minor from CLIMB2_minor.xlsx.
  2. Edit its four sheets as in sections 4 and 5: Program details, Stages, Structure, Streams. Delete the rows you don't need; the Climate courses won't disappear on their own.
  3. Add a row to programs.xlsx, sheet Programs:
programs.xlsx, Programs sheet
FileMajorButton labelShow
CLIME1_bsc.xlsxClimate Systems ScienceBScyes
CLIMB1_advsci.xlsxClimate Systems ScienceAdvSciyes
CLIMB2_minor.xlsxClimate Systems ScienceMinoryes
GEOSA1_bsc.xlsxGeologyBScyes
  • File is the workbook's file name, exactly.
  • Major groups programs together. Rows with the same Major share one page and appear as buttons; each different Major is an entry in the drop-down.
  • Button label is the short text on the button.
  • Show: yes to show it, no to hide it while you're still working on it. Handy for drafting a new major without students seeing it.
  1. Run the scraper (section 7) so the new program's courses get their titles and details.
  2. Reload the page and press Check.

The Settings sheet of programs.xlsx holds text that applies to every program: the site title shown above the drop-down, the feedback email, the "suggested pathways" wording, and the myPlan and WIL links.

7. The handbook details and when to run the scraper

handbook.xlsx is where the page gets each course's title, the terms it runs in, its prerequisites and exclusions, and its handbook link. You don't type any of this. The scraper (scrape_handbook.py) fills it in by reading the UNSW Handbook website.

How the scraper knows which courses to fetch

It reads programs.xlsx to find the program workbooks, then collects every course code in the Course, Alternative and Stream columns of all of them. So you never give it a list: if a course is on any map, it gets fetched. Codes mentioned only in a Note column are ignored.

When to run it

  • Whenever you add a course code that wasn't on any map before. Until you do, the new tile says "Title to be confirmed" and the Check button will flag it.
  • Once a year when the new Handbook is published (usually September or October), and again a few months later, because term offerings are sometimes added after the structure. The footer of the page shows which handbook year the details came from.
  • Any time you suspect the details are stale.

You do not need to run it after moving courses between stages, changing pathways, changing UoC numbers, or editing notes. Those come straight from the program workbooks.

Running it

You need Python 3 on your computer and normal internet access (the UNSW network is fine). Open a terminal (Mac: Terminal app; Windows: Command Prompt or PowerShell) in the course map folder.

First time only, install the packages it needs:

pip install -r requirements.txt

If pip is not found, try pip3 or python3 -m pip.

Each time:

python scrape_handbook.py

It prints one line per course as it goes and finishes with a summary of anything it couldn't find. It takes about a minute. Other useful forms:

python scrape_handbook.py --year 2027     # a particular handbook year
python scrape_handbook.py --dry-run       # just list the codes it would fetch

Without --year it uses the newest handbook year that exists. The year it used is written into the Info sheet of handbook.xlsx and shown in the page footer.

The scraper rewrites the Courses and Info sheets of handbook.xlsx every time. Never type into those two sheets; anything you put there is lost on the next run. Corrections go in Overrides (next section), which the scraper never touches.

8. Fixing course details by hand: the Overrides sheet

Sometimes the Handbook is wrong, out of date, or doesn't have a course yet (a brand-new course, or a code that is changing next year). The Overrides sheet in handbook.xlsx is for this.

It has the same columns as the Courses sheet. The rule is simple: any cell you fill in here replaces the scraped value for that course. Blank cells are ignored. So you only fill in what you want to change.

Overrides sheet (extract)
CodeTitleUoCTermsPrerequisites...Error
BEES1042(the new course’s title)6Term 1
GEOS3922Term 2

In this example, BEES1042 is a new course not yet in the Handbook, so its title, UoC and term are all typed in by hand. GEOS3922 is in the Handbook but has no term listed, so only Terms is filled in; its title and everything else still come from the scrape.

  • A course that is in Overrides but not in Courses (like BEES1042 above) is simply added to the map.
  • Overrides survive every scraper run. When the Handbook catches up, delete the override row so the live details are used.
  • Write terms the way the Handbook does: Term 1, Term 2 (with commas). From 2028 this will be semesters; use whatever the Handbook uses.
  • The Prerequisites column is free text, shown in the side panel. The page picks course codes out of it to draw the prerequisite links, so include the codes.

9. Checking your work

Press the Check button in the page header after any edit. It reads all the files and lists anything that doesn't add up.

The Check panel. Red items mean something will be missing or wrong on the map; amber items are worth a look but not urgent.

Typical messages and what to do:

MessageWhat to do
"...is in the Structure sheet but not in handbook.xlsx"Run the scraper, or if the course isn't in the Handbook yet, add it to Overrides.
"...has no title in handbook.xlsx"The scraper couldn't find it. Check the code is right; if it's a new course, put a title in Overrides.
"...has no offering terms listed"Usually the Handbook hasn't published them yet. Ignore, or add them in Overrides if you know them.
"Stream ... lists X, which is not on this program's map"Either add X to the Structure sheet as an Elective, or remove it from the pathway.
"Stream ... lists X, which is a core course"Remove it from the pathway; core courses are compulsory anyway.
"Core UoC is 24 in the Stages sheet but the core rows add up to 30"Fix whichever is wrong.
"...must choose 12 UoC of electives but the pool only has 6 UoC"Add electives or reduce Elective UoC.

The count on the Check button goes red when there is at least one real problem and amber when there are only warnings. Aim for zero before the page goes live.

10. Looking at the page and putting it live

Looking at it on your own computer

Web browsers won't let a page read spreadsheets straight from your disk, so double-clicking course_map.html shows an error. Instead, open a terminal in the folder and run:

python -m http.server

then go to http://localhost:8000/course_map.html in your browser. Leave the terminal window open while you look. Every time you save a spreadsheet, just reload the page.

Putting it live

The live page is simply this folder copied to the website. Copy the whole folder (including lib/) so the spreadsheets sit next to the page. How the copy happens depends on the site; at the time of writing the folder lives in the teaching/bees_course_maps/ part of Alex Sen Gupta's site and is pushed with the rest of it.

Sharing a link to one program

The web address remembers which program (and pathway) is showing, so you can link straight to one: course_map.html#CLIME1_bsc opens on the BSc. The part after # is the workbook's file name without .xlsx.

Printing

The Print button gives a one-page landscape summary of the program on screen, for handbooks and induction slides.

11. If something goes wrong

What you seeLikely cause and fix
"Could not load the course map"The page was opened by double-clicking, or a file it needs is missing or misnamed. Use the local server (section 10) and check that programs.xlsx, the workbooks it lists and handbook.xlsx are all in the same folder as the page.
A program has disappearedIts row in programs.xlsx has Show = no, or its file name doesn't match.
A course shows "Title to be confirmed"It isn't in handbook.xlsx. Run the scraper, or add it to Overrides.
A course tile is missing altogetherThe code is mistyped (must be four capital letters + four digits), its Stage doesn't match the Stages sheet, or its Type isn't exactly Core, Elective or Degree.
"Choose one" group not appearingThe alternatives must be in the Alternative columns, not in the Course cell with a slash. A slash means co-badged (same course, two codes), not a choice.
The scraper says "not in 2027 handbook" for a courseEither the code is wrong, or the course is new. New courses go in Overrides until the Handbook lists them.
The scraper won't run at allCheck Python is installed (python --version) and the packages are installed (pip install -r requirements.txt). Some university networks block scripts from fetching web pages; try from home or on Wi-Fi.
Changes don't show after savingMake sure you saved as .xlsx in the same folder, then do a hard reload of the page (Cmd+Shift+R on Mac, Ctrl+Shift+R on Windows).
