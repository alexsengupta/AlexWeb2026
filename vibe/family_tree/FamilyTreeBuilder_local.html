How to use Family Tree Builder

Getting started

Select a card to edit details. Use the buttons in the right panel to add parents, partners, children, or siblings. Unknown cards are placeholders you can click to fill in later.

Build relationships

  • Use Add Parents/Partner/Child/Sibling to grow the tree.
  • Use Move Earlier/Later to reorder siblings or partners within a family.
  • Set a focal person to center the layout around a specific line.
  • Click the arrow on a connector line to collapse/expand that branch. Each union can be collapsed independently.

Navigate

  • Drag the canvas to pan. Scroll or use + / − to zoom.
  • Use Zoom to Extents to fit the whole tree in view.
  • Undo lets you step back through recent edits.

Save and share

  • Use Save/Load for JSON backups.
  • Autosave writes JSON to a chosen folder and filename.
  • Export GEDCOM to share with other genealogy tools.
  • Data View opens an editable, filterable table of all people.
  • Reports: Full Tree and Bloodline export as vector PDFs.
